# QF5210 Group Project — Submission Package (revised 31 Oct 2026)

**Group:** Fat Tails
**Project:** The Quadrant Strategy — Four Market Structures. Four sleeves, weights
20/15/50/15: E1 PCA mean reversion (20) / Nasdaq-100 dip-buying (15) /
crypto options wheel (50) / short IDR (15).
**Book (common window, Apr 2021 to Oct 2026, 291 weeks, all in USD):** Sharpe 1.39,
CAGR 21.4%, vol 14.8%, max DD −14.9%, total +196.4%. October 2026 live window:
+1.42% (+18.7% annualised). Full statistics: `outputs/book/deck_stats.json`;
October window: `outputs/book/window_2026-10-01_2026-10-30.json`, with the
per-sleeve tear sheet in `outputs/book/tearsheet_2026-10-01_2026-10-30.json`.
**Submission deadline:** Sat 31 Oct 2026, 23:59 SGT (Canvas). Presentation Wed 4 Nov, 20:30–20:40.

## Contents
- `slides/` — the presentation deck (PDF, 21 pages: 12 main slides plus
  appendix A1–A9) plus the same deck with the Monte Carlo forward test
  appended as appendix A10 (22 pages).
- `assets/` — the deck's editable source (`assets/deck/deck.html`, the file
  the PDFs in `slides/` are printed from) and its chart images
  (`assets/deck/img/`), regenerated by `code/scripts/book_report.py`.
- `code/` — the full strategy source: `book/` (config with every frozen
  parameter, sleeve modules, portfolio construction, Monte Carlo forward test)
  and `scripts/` (data fetch, sleeve runs, window evaluation, tear sheet,
  book report, deck build), plus `notebooks/QF5210_strategies.ipynb` which
  runs everything in slide order.
- `data/` — every input series the sleeves run on, by sleeve.
- `outputs/` — computed results: per-sleeve returns, trades and summaries, the
  book statistics, the October window evaluation and tear sheet, and the
  Monte Carlo forward test outputs the appendix slide draws on.
- `requirements.txt` — Python dependencies.

## How to run
```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
python code/scripts/run_sleeves.py        # every sleeve (inputs already in data/)
python code/scripts/evaluate_window.py    # October 2026 window, annualised
python code/scripts/book_report.py        # book-level numbers and charts
```
(Scripts resolve paths from `code/book/config.py`; run from the package root.
Verified 31 Oct 2026: `book_report.py` regenerates `outputs/book/deck_stats.json`
exactly, and `evaluate_window.py` reproduces the October window.)

## Package adaptations
Two small changes were made to the packaged code only, so the package
reproduces its own outputs; the team repository is unchanged:
- `code/book/config.py`: `ROOT` resolves one level higher (the package nests
  the code under `code/`), so `data/` and `outputs/` are found at the package root.
- `code/book/sleeves/dip.py`: the attribution line follows the group's agreed
  wording for submission files.
- `data/portfolio_daily_closes.csv`: added to match the brief's data wording,
  the combined list of portfolio assets with their daily closing prices
  (128 series, 2014-01-02 to 2026-10-30), merged from the per-sleeve CSVs
  under `data/`.
- `assets/deck/deck.html`: at the group's direction on 31 Oct, one row was
  removed from the appendix A3 rejection log (the summary counts on that slide
  were adjusted to match), and the PDFs in `slides/` were reprinted from the
  edited source.
